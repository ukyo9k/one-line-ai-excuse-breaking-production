The funniest one-line excuse an AI gives its human right after breaking production — in the machine's own voice, with a specific, painfully plausible detail. One line, 119 characters, no setup wasted.

## Run it

```sh
python3 main.py
```

This writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is unset). The program validates the line before writing: exactly one line, 1–180 characters, not only whitespace, valid UTF-8 — and re-reads the file to confirm the bytes it wrote.
